# CM66 BDCARS

Веб-ассистент для быстрого поиска автомобилей в рабочей базе.

Проект помогает менеджеру найти подходящие варианты по свободному текстовому запросу: марка, модель, город, бюджет, коробка передач и другие параметры. Результаты выводятся в формате компактных карточек с основной информацией об автомобиле.

Ассистент рассчитан на простое использование внутри CRM или как отдельная рабочая страница для команды продаж.

## Возможности

- поиск автомобилей по разговорным запросам;
- поддержка синонимов марок, моделей и городов;
- фильтрация по бюджету;
- карточки с ценой, годом, городом, пробегом, характеристиками и фото;
- локальная история чата;
- служебные команды через `/`.

## Назначение

Это внутренний инструмент для ускорения подбора автомобилей и подготовки вариантов для клиента.
